# 中文学术写作：术语、现象与科学含义

适用于 AI 研究的中文起草、翻译与审校。目标是让读者准确理解研究问题和证据，采用自然的中文学术表达。英文稿沿用相应语言的规范；已经准确、清楚的中文无需重写。

## 六条规则

1. **先理解含义，再选择中文表达。** 先明确原文描述的对象、动作、关系和条件，再决定怎样写。不要逐词对应英文，也不要照搬英文句法；专业概念不能仅凭字面翻译确定。
2. **优先采用领域惯用术语。** 参考同领域可靠中文文献、作者已有术语表及通行用法。必要时首次给出英文原词或缩写，后文保持一致。已有规范名称无需为了“更中文”而改写；不能确认的术语只补查相关来源，不为局部措辞重做全量检索。
3. **译词不清楚时，直接描述现象。** 说明什么对象发生了什么变化、哪些关系出了问题。避免把一个生硬译词换成另一个抽象标签；描述应简洁、正式，也不能为了通俗而丢失专业信息。
4. **改表达，不改科学含义。** 保留对象、比较方向、适用范围、因果强度和不确定性。局部关系与整体性质、相关与因果、改善与保证不能互换；数字、方法步骤和引用不随润色改变。含义确有歧义时，交作者或领域专家核对。
5. **按中文习惯组织学术论证。** 主体明确，搭配自然，一句承担清楚的判断，避免名词堆叠和空泛修饰。段落围绕研究问题比较已有进展与不足；不能为衔接顺畅而编造因果、时间演进或方法继承关系。借鉴同行的论证方式，不搬用独特句式。
6. **按语境吸收反馈，采用最小必要修改。** 用户对当前用词的纠正按其明确确认的修改范围落实；额外改写或记录偏好先讨论确认。区分领域术语、客观表达问题和个人偏好；不将一次反馈变成全领域禁词表。若局部换词已能解决问题，就保留其余准确文字。

## 用语示例与适用条件

以下是含义对照，不是全文替换表，也不承担文献或实验结论。

| 语境与原表达 | 更清楚的表述 | 含义核对 |
|---|---|---|
| 气道分割中的 leakage 直译为“泄漏” | “将周围肺组织误分为气道” | 仅当原文确指这类误分割；不能用于代指所有分割问题 |
| 分支分割中的 false connections 写作“错误连接” | “将本不应直接相连的分支连接起来” | 指多出了不应存在的直接连接；不把同一棵树中的这些分支写成整体互不连通 |
| 训练与评估信息混用中的 data leakage | 保留“数据泄漏”，必要时说明测试信息通过哪条路径进入训练或模型选择 | 同一中文词在不同专业语境中可以合适，不机械替换 |

同样，“低对比度”等常用专业表达可以保留；若读者难以理解，再说明具体对象与周围组织的影像差异。自然的中文学术写作不等于把所有专业术语改成口语。

## 写作与审校怎样落实

- `writing` 起草或修订时，先确认句子要表达的科学判断，再选择术语与句式；已有核实的原文和术语约定可复用。
- `review-writing` 独立检查直译、搭配及歧义，用“原句 → 问题与适用语境 → 最小改写 → 含义是否保持”给出必要意见。两种表达都成立时标为可选，不为显示工作量重写。
- 涉及专业概念或科学主张变化时，与 `review-domain` 和作者核对；普通措辞修正也按[共享约定](../agents/README.md)先讨论确认。用稿件前后对照检查原问题是否解决、是否引入新歧义，不按替换词数衡量质量。
- 用户明确偏好留在本地用户档案；项目经验和候选策略按 [RSI 约定](rsi.md)保存。公共规则只保留可复用的做法，不复制私有稿件和个人反馈记录，也不将写入规则称为能力已获验证。
