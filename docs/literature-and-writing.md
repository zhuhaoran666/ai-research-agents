# 看别人怎么做，也看别人怎么写

本文定义文献驱动的研究与写作方式：站在巨人的肩膀上，围绕实际问题和初步解法展开，借鉴已有方法与文章/图表组织方式，通过真实实验、分析和写作逐渐完善方案。写作与最终审稿都需要扎实的文献阅读；这些指令不代表已替新课题完成检索或审稿。

## 贴近实际研究的推进方式

| 当前在做什么 | Agent 怎样协作 | 留下的材料 |
|---|---|---|
| 有一个问题和初始解决方法 | 你与 `method` 说明目标、方法直觉和当前未知 | 研究笔记中的初步设想 |
| 查这个问题是否已被解决 | `literature` 必查 PaperNotes、Google Scholar、arXiv，按[领域来源](literature-sources.md)检索会议、期刊和数据库，查已有解法、任务条件与局限，找到合理基线 | 简短方法比较及来源 |
| 找其他可能可用的方法 | `literature + method` 查相邻领域的机制，说明哪些条件相似、需要什么适配；你参与选择值得试的方案 | 方法候选和最小实验 |
| 做实验并积累记录 | `code` 统一实现和运行；`analysis + method` 整理有效结果、失败及优化选项 | 代码配置、运行日志、结果表 |
| 结果足以形成初步认识 | 你与 `analysis + writing` 集中分析，确定文章主线，写作画图 | 草稿、科研图表及证据缺口 |
| 边写边改进 | `writing` 提出论证缺口，`method/analysis` 区分补写、补分析、补实验或改方法 | 更新的方案、结果和稿件 |
| 最终集中审稿 | 独立 `reviewer` 广泛阅读并补查，对贡献、方法、比较和结论提出实质意见 | 优先级明确的审稿报告 |

`mentor` 贯穿以上工作：统筹方向与优先级、复查七个角色的协作和自身判断，在重要意图不清时与你确认，并根据明确偏好和反馈改善后续协作。日常分工直接推进。

不设“积累到多少实验才能写”的数字门槛。早期可以记录段落想法；集中写作从已有结果能支持初步叙述时开始。文献调研、实验和写作可相互触发，不要求按表逐项验收。

## 一份文献库，两种阅读目的

**看怎么做：** 同问题已有方法、合理基线、可迁移机制、任务假设、适配、实验设置、结果与失败边界。

**看怎么写：** 同类型好文章怎样提出问题、比较已有工作、引出方法、组织模块、安排对照、用图表支持判断，以及怎样表述贡献和局限。记录可借鉴的组织动作和适用理由，用自己的材料写作。

读范文时同时记下“具体失败或矛盾 → 已有工作解决的部分 → 尚未回答的问题”和本课题能对应的真实材料。范文的论证功能可以迁移，未经验证的领域判断和独特句式不能迁移；引言引用只保留能推动论证的文献，不以篇数充实段落。

实际论文的拆解见[可选写作范例](../examples/writing-patterns.md)。新课题按问题、贡献类型和目标读者重新选择范文；示例中的领域和会议不构成固定要求。

文献池应覆盖同问题工作、最接近方法、基线与代表性方法、跨领域来源、近期发展和反证；写作参考再按任务、贡献类型或目标 venue 挑选。只引用或只搜索到一篇不等于读过它。

完整课题可从约 30–60 篇候选的广泛检索与筛读开始，重点精读约 10–20 篇与核心判断相关的全文章节，再沿引用追踪和新问题扩展。这些是工作量估算，不是完成标准或引用配额；窄问题可更少，跨领域问题可能更多，重要竞争工作不能因为达到数量而略过。少量写法范例不能替代广泛方法阅读。

## 怎样记录实际阅读

在现有研究笔记或 `literature/reading.md` 中维护一张表即可；复杂证据另存来源文件。

| 论文与 DOI/URL | 用于哪个问题或判断 | 谁读到哪里 | 方法要点与原文定位 | 可借鉴的写法与位置 | 限制/待查 |
|---|---|---|---|---|---|
| <真实来源> | <问题现状/基线/迁移/写作> | <writer/reviewer；摘要/指定章节/全文> | <实际读到的证据> | <论证或图表组织，可空> | <实际缺口> |

保留简短检索记录：来源、日期、关键词或分类入口和覆盖范围；注明 PaperNotes、Google Scholar、arXiv 与领域会议、期刊的实际检索情况及覆盖年份，未命中与访问受限分开记录。具体要求见[文献 Agent 的必查来源](../agents/literature.md)和[官方检索入口](literature-sources.md)。PaperNotes 解读与 Scholar 检索结果用于发现线索，关键判断回到原论文核实；记录 arXiv 所读版本及预印本、会议版、期刊版之间的关系。

原文位置可以是章节、页码、表图或段落；不要求每篇单独填一张长卡。已有阅读能复用，增量补查即可，但审稿人要独立核读支持其主要判断的来源。

模型记忆可帮助提出检索词，不能作为“已读文献”的凭据。元数据只能识别来源，摘要用于筛读；方法等价、局限和数值比较要回到实际原文。没找到文献不证明它不存在或方法首次提出；访问失败与检索无结果分别说明。

## 写作与审稿的独立性

[写作画图 Agent](../agents/paper-writer.md)学习已有研究的思路、表达和图形组织，围绕作者的真实结果建立论证；[审稿人 Agent](../agents/manuscript-reviewer.md)从同一实际问题出发，独立检查遗漏的解法、强基线和替代解释。两者共享来源，分别形成判断；导师汇总意见但不抹去分歧。

最终审稿人要主动搜索作者参考文献以外的研究，特别是不同术语下的相近问题、简单但强的方案和反面结果。每条主要意见应能说明“哪项证据使我担忧，以及它影响论文的什么结论”。补查未发现实质问题时如实说明，不为完成审稿而虚构缺陷。

最终报告简要披露实际覆盖与阅读深度，优先呈现会改变结论的问题。若关键原文或实验材料不可取得，提供已成立的意见并说明无法判断的范围；不能以广泛浏览或作者自评代替完整的最终审查。局部章节反馈不用每次重做全量调研。
