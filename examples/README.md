# 可选示例

这些材料演示如何使用框架，不限定研究领域、方法、数据集或投稿 venue。

- [一次研究协作](research-project.md)：从一个虚构的高效适配设想出发，展示七个角色怎样接手和迭代。没有已完成的检索、实验或结果。
- [论文写法观察](writing-patterns.md)：基于实际阅读的三篇论文引言，展示如何学习论证组织，同时保留自己的问题与证据。
- [导师逐步引导对话](../docs/mentor-guided-intake.md)：从初步现象、代码或已有结果开始，分轮补齐当前所需信息。
- [可运行的证据链](evidence-demo/README.md)：四条合成预测的评价与追溯，演示可选检查器；数字只用于演示。

新课题可直接使用[研究笔记模板](../templates/research-note.md)，按真实材料替换示例设定。角色按需启动，交接可在同一笔记内完成；无需复制全部目录或另建七个工作窗口。
