# Agent 改进记录（可选）

配合[RSI 约定](../docs/rsi.md)。只记录值得复用的变化，日常小修正直接完成，不必填表。实际记录留在项目笔记或本地 `profiles/agent-learning/<角色 ID>.md`，不要把私有材料复制进公共模板。

- 角色与反馈来源：<用户原要求/可定位的实际问题；自己的解释单独注明>
- 当前不足与修改：<旧做法、具体新做法；是否也调整了诊断或验证方法>
- 检验依据与结果：<原文/代码/运行/文本/反馈位置；实际检查、改善与退步；未检验则明确>
- 保存范围与状态：<仅本任务/项目/角色可复用；待检验/在某条件下支持/已撤回>
- 版本与撤回：<改动或旧文件位置；什么结果会使该规则失效>

用户明确偏好与验证过的工作经验分开；已经撤回的做法不自动恢复。下一次任务只加载仍有效且适用的部分。
