# 简短任务说明

- 交给谁：<负责的 Agent 或角色>
- 要做什么：<当前问题与希望得到的结果>
- 已有资料：<研究笔记、论文、代码或数据位置>
- 交付什么：<代码、实验结果或简短分析>
- 操作清单与用户确认：<逐项说明动作、目的、范围及影响；记录用户明确确认的消息或位置；待讨论项不可执行>
- 新想法与等待边界：<发散或替代方案先讨论；等待时只执行已确认动作，没有则等待；子代理继承同一边界>
- 需要注意：<仅写有关的时间、GPU 预算、比较条件等；已有约定直接引用>

## 完成后补充

- 结果及位置：<实际产物；未执行的内容注明>
- 发现的问题与下一步：<影响研究判断的内容即可>

可在对话或研究笔记中使用这些字段，无需另建文件。按[共享约定](../agents/README.md)，每项操作先讨论并明确确认，也可一次确认列清的操作清单；总体目标、资源额度和导师派工都不替代用户确认。复杂任务可按需增加输入、资源、输出格式和验收条件。
