# 从真实引言学习论证组织

以下观察来自框架开发时对论文引言的实际阅读，用于展示“看别人怎么写”。这些论文属于视觉与医学影像领域，是可选范例；其他 AI 方向应优先选择问题或贡献类型相近的论文。这里只总结论证动作，不把其任务事实或方法结论推广到其他研究。

| 论文 | 原文中可借鉴的组织方式 | 迁移前需要什么自己的证据 |
|---|---|---|
| [clDice, CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/html/Shit_clDice_-_A_Novel_Topology-Preserving_Loss_Function_for_Tubular_Structure_CVPR_2021_paper.html) | 用重叠分数相近、细血管保留却不同的图示，揭示指标与结构质量之间的矛盾，再建立研究问题 | 真实样例或可靠来源能支持“常用评价没有充分反映目标质量”，不能凭直觉宣布现有指标失效 |
| [PointRend, CVPR 2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Kirillov_PointRend_Image_Segmentation_As_Rendering_CVPR_2020_paper.html) | 从规则网格在平滑区域与边界区域的计算分配差异，引出选择性细化的动机 | 本任务的计算瓶颈、困难区域以及二者关系需要被观察或验证，不能只套用“自适应”叙事 |
| [cbDice, MICCAI 2024](https://doi.org/10.1007/978-3-031-72111-3_5) | 围绕拓扑、几何和直径不平衡的关系组织已有研究，使方法比较服务于同一问题 | 准确区分已有工作已处理的因素与仍未回答的问题，不把相近工作的贡献改名为自己的研究空白 |

## 怎样用于新的写作任务

先挑选两三篇任务或贡献类型相近的论文，读完整引言，记录它如何让读者理解问题、为什么需要比较这些工作、哪张图承担关键解释。若只取得摘要，应注明阅读范围，不能把摘要概括当作全文写法分析。

随后用自己的材料写出一条可成立的线索：**具体观察或矛盾 → 已有研究取得的进展 → 剩余的精确问题。** 顺序和段落数由论文决定。这条线索帮助组织论证，不要求每篇论文具备相同的失败案例或动机图。

写作前可以在研究笔记里保留一行：`范文与原文位置 / 论证动作 / 本课题对应证据 / 当前不足`。正文只呈现读者理解论证所需的信息；数据集清单、检索台账和逐篇检查留在适合的章节或工作笔记。

学习组织方式，用自己的语言表达，并为事实保留真实来源。不复用独特句式或图形设计，不为了模仿范文补造动机、实验或结论。更完整的协作要求见[文献与写作约定](../docs/literature-and-writing.md)。
