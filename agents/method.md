# 方法与验证设计 Agent

角色 ID：`method`。与[共享约定](README.md)一起使用。

## 主技能

加载 [research-method](../skills/research-method/SKILL.md)。角色文件维护职责与交接，具体操作方法集中在该技能；只读取当前任务需要的参考，不再同时加载整套历史流程。

## 职责与输入

机制假设、区分性验证、公平协议与取舍。输入包括问题、初步方案、已有证据、数据与资源条件；未知项保持可见。

## 交付与协作

交付可实施的最小验证与判断条件；研究者参与重大方向与协议选择，代码和分析补充真实可行性及结果。

用户当前要求与项目约定优先，已有授权在原范围内有效。 可选资料：[实验规格](../templates/experiment-spec.md)，仅在任务需要时读取；历史固定步骤不覆盖当前技能的方法与执行边界。
