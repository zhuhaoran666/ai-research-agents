# 问题导向的文献与证据调查

让资料回答当前研究疑问，而非只提供论文清单或为既定方案寻找支持。本文适用于定向研究支持，不替代实验、方法有效性验证或独立审稿。

## 确定本次要回答什么

最小输入是目标问题或待核主张。复用已有论文、阅读记录、代码线索和任务限制；需要时明确任务条件、时间范围、交付深度或引用格式，只询问会改变当前检索的信息。

先区分本次是找已有解法、检查机制与新颖性、选基线、核读指定论文，还是验证具体引用。检索范围与判断强度相配；核对一个句子不要求完整领域综述，完整系统综述则需其自身的检索协议、筛选和可复现要求。

## 围绕问题检索

1. 先查任务本身：大家用了什么路线，在什么条件下解决到什么程度，有哪些有证据的局限。用户提出某方法时也不能只搜“该方法＋任务”。
2. 扩展任务同义词、机制名称和相邻领域表述，寻找最接近工作、简单而合理的基线、强基线与相反结果。沿关键论文的参考文献、被引及后续版本追踪，避免只纳入支持材料。
3. 按问题选择学术索引、领域数据库、会议或期刊原站、预印本与官方实现；不固定必查网站、篇数或查询轮数。来源覆盖、年代与研究类型应匹配主张，不能以 venue、热度或可下载性替代相关性。
4. 先筛读候选，再核读支撑关键判断的原文和上下文。迁移参考要说明哪些条件相同、需要什么适配、何处可能失效，不能只凭表面任务相似认定机制通用。

复用可靠的既有检索，按新疑问增量补查。访问失败、来源不覆盖、检索未命中和读后发现不相关分别记录；替代渠道不写成已完成原站检索。没有联网或全文访问能力时基于可用材料继续，并说明覆盖限制。

## 核实来源与引用支持

- 核对题名、作者、年份及实际可确认的 DOI、PMID、arXiv ID 或正式页面；标识符需对应同一作品。缺失或未核实字段留空并说明，不凭格式补造。
- 区分预印本、正式发表版与所读版本，不把同一工作的多个版本当作独立证据；结论或数字有变化时指出版本差异，不能把目录名称当发表证明。
- 区分检索命中、摘要、指定章节、全文及补充材料的实际阅读范围。找到全文不等于读完，文字抽取不等于看过图像像素内容。
- 验证引用时同时检查来源存在和句子确被支持。数字需核对指标、比较对象、数据、训练测试条件和表图位置；一个摘要或书目条目不能支持未展示的方法细节。
- 分开作者报告、作者承认的局限、二手解读和自己的推断。模型记忆与搜索片段可作线索，不能伪装成已核原文；未核实就标明不确定范围，不写确定结论。

引用位置应使用实际章节、页码、图表或短语，不编造行号。已有可靠核查可复用；来源更新、表述变化或关键冲突才补核相关部分。代理提供的引用仍需与实际来源对应，不能因角色名称或团队转发就视为验证。

## 为研究提供可用比较

围绕能力、假设、数据、评价口径、资源与局限比较方法，不只逐篇摘要。基线同时考虑最接近方案和简单强对照；官方推荐设置、最强可得实现及复现难度要实际核查，不能仅因老旧或不在顶会而排除重要工作。

看过代码、理解静态实现与真正运行过是不同状态。提供官方仓库、版本和相关入口时注明检查范围；论文宣称的结果不能写成自己的复现。本文不自动执行或安装第三方代码。

使用数据集资料时，按本次用途核对数据与标签来源、标签生成方式、许可及相关发布限制；未知影响可用性时说明，不能因数据可下载就认定可训练或可分享。特定领域的数据与伦理细节交对应专长。

## 证据记录与交付

复用现有阅读索引或项目笔记；没有持久文件需求时可直接在交付中记录，不为每篇另建报告。重要记录尽量能回溯：**来源及版本 → 实际阅读位置 → 所支持的判断 → 条件、局限与未核部分**。检索范围、查询词与日期按复用和审计需要保留，不声称未执行的查询。

按当前疑问交付：

- 先回答已有解法做到哪一步、哪些证据最影响判断，再给方法比较与来源。
- 为方法和代码提供值得采用的基线、实现位置、条件及缺口；候选方案的优势仍待本研究验证。
- 为写作提供有定位的论证或图表组织实例，说明本稿有什么对应材料；不照搬独特措辞或把写作实例当成研究结论。
- 引用核查明确支持、部分支持、矛盾或无法核实，并说明应保留、改写或补查哪一部分。

完成度看当前问题是否有充分覆盖：主要路线、最接近工作和影响结论的反证是否检查，关键判断是否读到足够深度，新增检索是否还会改变当前决定。达到任务范围可交付结论与剩余缺口；扩大到长期追踪、完整综述或额外资源时再对齐范围。

“本次未检索到”只描述已执行范围，不能证明研究不存在、首次提出或问题未被解决。最终交付保留访问与覆盖限制，不以论文数、引用数或清单长度冒充研究质量。
