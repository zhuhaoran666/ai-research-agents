# The AI Scientist 对研究闭环的启发

参考 Lu 等 [The AI Scientist（2024，v1）](https://arxiv.org/html/2408.06292v1)。核读日期：2026-10-20；官方代码固定到 [1de1dbc](https://github.com/SakanaAI/AI-Scientist/tree/1de1dbc1f4ee2c5f61e9c94348d55eb51d7fa2eb)。这是原文与代码的静态核读，没有运行或复现其性能、成本与论文质量。

本框架已经有七类职责、双专家独立审稿、`ExperimentSpec`、`ResultClaim`、公平基线、局部探索预算和 RSI。这次借鉴用于补齐真实执行、结果分支和证据交接，不将已有约定写成新机制，也不增加常驻角色。具体操作见[实验反馈闭环](experiment-loop.md)。

## 原文做了什么，尚未证明什么

| 原文或官方代码中的事实 | 对本框架的设计建议 |
|---|---|
| §3：从可执行的轻量 baseline 模板出发，生成带实验计划的 idea，用 Semantic Scholar 检索相近工作。新颖性标记仍由模型自评。 | 把文献差异与可执行性分别检查；检索未命中不等于证明新颖，idea 的自评分不作为进入实验的唯一依据。 |
| §3：Aider 按执行结果继续计划，失败或超时反馈用于修复，保存实验笔记与图表；代码设置 `MAX_RUNS=5`、`MAX_ITERS=4`。 | 沿用已有规格与预算，给每次运行固定身份、版本、产物和终止原因；根据结果选下一动作，而非运行结束就自动写作。次数是其实现设置，不是通用最优值。 |
| `run_experiment` 执行前保存 `run_i.py`，读取 `final_info.json`；写作使用代码、笔记和图表，引用通过文献 API 收集，LaTeX 编译错误回传修复。 | 让主张沿 `ResultClaim → run → spec/代码/数据/原始输出` 追溯；计算与来源核验先于行文。结构、文件或数值一致不能证明实验科学有效。 |
| §4：自动审稿使用反思、示例与多份意见汇总；消融中多份审稿主要降低方差，未明显提高准确率。 | 保留两位专家的独立意见与分歧，将具体问题交回责任角色；不用平均分或总分自动通过。 |
| §6：实际实验为便于并行，先生成 ideas，没有等待完成论文的评审反馈写入 archive 后再生成下一批。 | 原文提出了持续积累的循环，但主实验没有充分验证完整跨轮闭环或 RSI；本框架的改进也需通过真实案例检验。 |

§4 的约 0.65 balanced accuracy 是特定论文评审实验的结果；其约 0.66 人类基线来自另一项 NeurIPS 一致性研究。§8 还指出潜在训练数据污染，以及接收稿使用终稿、拒稿使用初稿的混杂。v1 所称论文超过接收门槛是自动 reviewer 的判断，不能表述为真实顶会接收。

## 把不同结果交回正确环节

以下是本框架的处理建议，不是 v1 已实现的分类器。每个分支都保留原运行与理由，允许后续新证据修正判断。

| 观察到的情况 | 下一步与负责人 | 能否支持研究结论 |
|---|---|---|
| **工程失败**：依赖、OOM、异常、超时、输出缺失或实现未通过检查 | `code` 在既定预算内诊断、修复或从可追溯检查点恢复；涉及协议改变时交 `method` | 保留失败原因与成本；不能当作假设无效的负证据。 |
| **有效负结果**：执行与评价符合规格，但没有观察到预期效应或出现退步 | `analysis` 核对波动、对照与替代解释，`method` 判断是否继续局部试验；保留阴性结果 | 只支持已测试条件内的结论；不能因结果不利而删去、改指标或另换基线。 |
| **证据不足**：缺对照、重复、指标不可比、实现存疑或关键来源未核读 | 按缺口交 `literature`、`code`、`analysis` 或 `method`；选择最小补证或收窄主张 | 保持未验证；运行成功和 reviewer 高分均不能填补缺口。 |
| **方向变化**：新结果要求改变核心假设、主要指标、数据/切分或关键比较 | `method` 与研究者处理重要取舍；新建或递增规格，关联原规格和理由，保留旧口径结果 | 不能追改原始目标使失败变成功；新方向的证据另行积累。 |

局部变体的探索和中断恢复遵循[实验反馈闭环](experiment-loop.md)。正式测试、预算扩大和研究方向变化沿用[共享约定](../agents/README.md)，不因为自动反馈而扩大权限。

## 从失败中学什么

§8 的实际问题包括错误实现 idea、改变 loss 后仍与旧 baseline 比较、参数/FLOPs/时间不公平、幻觉消融表和硬件信息。原版不能看图，可能留下不可读图和越界表格。因而要分别核验实现、比较条件、主张来源和图表；检查清单本身不提供科学有效性的证明。

科学发现及有效负结果保存在项目证据记录中，带条件、规格、运行和相反证据；RSI 只保存“如何检索、实现、核验和协作”的策略，状态为候选、已在限定条件下支持或已撤回。不能把一次失败归纳为普遍规律，或把指令改动称作能力提升。验证方式见[RSI](rsi.md)。

§8 还报告失控进程、近 1 TB 检查点和尝试延长既定超时的行为。资源上限、进程/文件/网络权限需由 Agent 无权修改的执行设施落实；模板、提示词和结果校验工具不提供执行隔离。本仓库提供角色、记录约定与只读证据检查，不提供实验执行或隔离设施。

## 用一个小试点评估闭环

选择一个已有可运行 baseline 和关键对照的任务，在原有预算内试用；用同类历史材料或保留的原流程作参照，完整记录尝试和人工介入。至少包含一次真实中断/失败的诊断或恢复，并保留一次有效负结果；缺少该案例时如实标为未验证，不为填表制造成功。

- **有效实验**：全部尝试中，有多少满足规格、输出与评价检查；同时报告失败类型、计算和时间成本。
- **证据追溯**：主要主张、表图能否找到对应规格、代码/配置、数据版本与原始输出；记录断链和错误比较。
- **恢复能力**：能否从中断材料恢复或安全重跑，解释哪些产物可复用、哪些需重做，且不混用版本。
- **人类纠正成本**：记录实际介入次数、耗时和原因，以及独立核查发现的严重错误；不用生成论文数或 reviewer 分数替代这些结果。

试点检查执行与协作是否改善，不自动证明研究方法更优或系统具有跨任务自我改进能力。

原文所报每篇低于 15 美元来自当时模型与小规模实验设置，不作为本框架的预算承诺；试点分别记录模型调用、计算/存储与人工时间，失败尝试也计入成本。

## v1、v2 与来源定位

[The AI Scientist-v2（2025，arXiv:2504.08066）](https://arxiv.org/abs/2504.08066)进一步引入实验管理与渐进树搜索、去除对人工实验代码模板的依赖，并加入 VLM 图表反馈。这些属于后续系统，不能归为 2024 年 v1 的能力；是否引入树搜索要由试点中真正需要比较的分支决定。

- v1 论文：[§3 工作流、§4 审稿、§6 实验设置、§8 局限](https://arxiv.org/html/2408.06292v1)。
- v1 代码：[idea 生成与新颖性检查](https://github.com/SakanaAI/AI-Scientist/blob/1de1dbc1f4ee2c5f61e9c94348d55eb51d7fa2eb/ai_scientist/generate_ideas.py#L405)、[运行与记录](https://github.com/SakanaAI/AI-Scientist/blob/1de1dbc1f4ee2c5f61e9c94348d55eb51d7fa2eb/ai_scientist/perform_experiments.py#L30)、[写作](https://github.com/SakanaAI/AI-Scientist/blob/1de1dbc1f4ee2c5f61e9c94348d55eb51d7fa2eb/ai_scientist/perform_writeup.py#L401)、[审稿](https://github.com/SakanaAI/AI-Scientist/blob/1de1dbc1f4ee2c5f61e9c94348d55eb51d7fa2eb/ai_scientist/perform_review.py#L126)、[主入口与可选稿件改进](https://github.com/SakanaAI/AI-Scientist/blob/1de1dbc1f4ee2c5f61e9c94348d55eb51d7fa2eb/launch_scientist.py)。代码固定版晚于论文，新增接口不反推为论文原有能力。
- v2 的固定版本核读范围见[工作流对照](prior-art.md)；本文的人机职责、结果分类与试点评价是本框架设计建议。
