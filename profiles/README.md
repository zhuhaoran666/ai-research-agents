# 本地用户档案

[`user.example.md`](user.example.md) 是可复制的起点。将其保存为 `user.md` 后填写自己的领域、工具、协作方式和长期偏好。`user.md` 默认被 `.gitignore` 排除；如需跨设备同步，应自行选择受控的私有位置。

导师角色维护档案。用户明确说过的偏好可以直接记录；从行为推测的习惯保留来源与不确定性，不冒充明确指令。项目特例放在项目笔记，不能因为个人偏好改变实验事实或扩大工具权限。

各角色的 RSI 经验按需保存到本地 `agent-learning/<角色 ID>.md`，该目录默认不纳入 Git。记录具体改动、验证与适用范围，可参考[改进记录模板](../templates/agent-improvement.md)。它与用户档案分开：一次有效策略不自动成为用户长期偏好。新任务只加载适用记录，完整机制见[RSI 约定](../docs/rsi.md)。
